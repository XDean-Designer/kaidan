先读这几条（贯穿全文）

  1. 本期是基于 RTB 线上开单结账 的 优化改版，不改变其他未涉及的功能逻辑。凡本文未单独描述的交互、文案、接口，均沿用线上现有实现。
  2. 页面顶部顾客卡片变化：男女头像 更换为新素材；点击头像可切换散客性别，头像右侧显示「男散客 / 女散客」；「选择顾客」进入顾客列表，列表新增「男散客 / 女散客」选项，列表内 VIP 标签样式做了微调。
  3. 从顾客列表选择 会员 后，开单结账页顶部卡片切换为 会员样式。原会员信息卡默认 折叠 会员所持权益，本期改为 保持展开、展示全部持有权益且不可折叠收起；字段显示规则维持现有规则。会员姓名右侧的 VIP 标签只是原型展示用的临时资源，开发时保持该位置现有 VIP 标签逻辑不变。
  4. 添加项目 / 产品时的 UI UX 是本期最大的修改：参照博卡小店通的 sheet 弹窗样式，按现有逻辑做了适配；设计了 独特的选择员工 UI UX（点击卡片翻转成按钮进行相关选择）；设置折扣采用 拟物标尺组件。购物车添加项后，点击「下一步」进入 原有的开单结账结算页。
  5. 新增「快速消费」功能：无需常规流程的繁琐操作，只需输入金额即可完成开单结算，并 可选填 服务员工信息和备注。为线下调研后决定加入的重要功能。
  6. 该模块的 其他功能保持现有状态（挂单、结算、支付、会员卡业务等均以线上为准）。
  7. 输入与联动口径（原型已同步）：金额格式 整数≤6位、小数≤2位、上限 999999.99；「实收」可手动编辑并 反推折扣，吸附到最近 0.5 折档位；快速消费 空金额不可「去收款」。

交互行为与文案以 index.html 当前表现（含本版同步后的口径）为准。

1背景 / 目标 / 范围 / 能力映射

1.1 背景

RTB 线上开单结账经过一段时间运营，线下调研反馈：

  • 常规开单需先选顾客、选项目、配员工、设折扣、填备注，流程较长，存在「只想快速收一笔钱」的场景；
  • 顾客卡片与顾客列表在性别表达、头像素材上体验欠佳；
  • 会员所持权益信息默认折叠，收银员核对权益时需要额外操作；
  • 添加项目/产品时的信息组织与操作路径不符合当前门店操作习惯。

本期在不改变其他功能逻辑的前提下，对开单结账做定点优化。

1.2 目标

目标说明
快速消费仅输入金额即可开单结算，选填员工与备注
顾客卡片优化新头像素材；点击头像切换散客性别；卡片同步显示性别文案

回归可控其余功能沿用线上，避免范围蔓延

  • 保持展开、展示全部持有权益，不可折叠收起（区别于线上默认折叠）。
  • 字段显示规则维持现有规则不变（如：计次卡「余N次」、储值卡「余额xx元」、折扣卡「x.x折」）。

4.4 折扣档位 asRulerTick

  • 0 ~ 20 档（tick），每档 = 0.5 折；折扣率 = tick / 20。
  • 标签：tick=0「免费」；tick=10「5折」；tick=20「原价」；其余「N 折 / N.5 折」。
  • 实收手动编辑后反推 tick 并 吸附到最近档位（见模块 8）。

4.5 购物车分类计数

  • 按「页面 + 左侧分类组」计数红点；加购成功后 +1；初始为 0 且隐藏。
  • 购物车明细 / 移除沿用线上（bottom-bar 购物车图标展开 sheet）。

4.6 添加弹窗四宫格联动

字段输入联动

5交互细则 / 异常流

5.1 金额输入规则（快速消费金额 + 应收/实收统一）

规则说明
整数位≤ 6 位
小数位≤ 2 位
上限999999.99
下限0（不可为负）
小数点最多 1 个；禁止以「.」开头
前导 0自动剔除（输入 0 后再输数字视为替换，如 05 → 5）
空值不可提交；快速消费空金额点「去收款」toast「请先输入金额」

5.2 实收反推折扣

  • 实收输入时：实时按 实收 ÷ 应收 反推折扣并预览（吸附到最近 0.5 折档位文案）。
  • 实收失焦 / 点确定：吸附到最近 0.5 折档位，实收同步改写为该档位对应值，标尺与折扣文案一致。
  • 应收无效（为空/≤0）时回退：实收 = 应收默认值 × 折扣。

5.3 员工 / 备注（选填）

  • 员工：非必填；快速消费与添加弹窗各自维护选择状态，互不影响。
  • 备注：非必填；≤ 200 字，实时计数 n/200；空 / 全空格视为未填。

5.4 校验失败（toast）

条件提示
快速消费空金额点「去收款」请先输入金额
下一步（购物车为空）请先选择项目
下一步（购物车有项）已进入开单结账，请按现有流程完成结算
挂单已挂单
底部「+」按钮请选择项目
底部「+」按钮（s5 触发）选择项目或快速消费
办卡办理会员卡
s3 去收款进入收款结算

5.5 弹层交互

  • 遮罩点击关闭；员工 sheet 关闭（点遮罩/完成）保留已选状态，重进不重置。
  • 添加弹窗遮罩关闭不写入购物车；「确定」后写入并 toast「已加入 · 应付 ¥x.xx」。

8业务规则

  1. 身份切换：默认散客；选会员 → 会员；选男/女散客 → 散客。s2/s3 顶部卡片随身份切换，后续元素随卡片高度下移。
  2. 散客性别：默认男散客；卡片头像点击 / 列表选择均可切换；仅影响展示与随单记录。
  3. 会员卡权益：保持展开、全部可见、不可折叠；字段显示规则维持现有。
  4. VIP 标签：原型为临时展示资源；开发保持该位置现有 VIP 标签逻辑不变。
  5. 金额格式：整数≤6 位、小数≤2 位、上限 999999.99、禁「.」开头、前导 0 剔除、不可为负。
  6. 快速消费：空金额不可「去收款」（toast「请先输入金额」）；员工/备注选填。
  7. 实收反推：实收可手动编辑；反推折扣并吸附最近 0.5 折档位；实收改写为该档位对应值；应收无效时回退。
  8. 折扣档位：tick 0~20（0.5 折/档）；标签 免费 / 5折 / 原价。
  9. 数量：步进 1~999。
  10. 员工选择：两步翻转（点客/散客 → 小工/中工/大工）；多选；重进保留已选；回填「姓名·点客·大工」。
  11. 备注：≤200 字；空/全空格视为未填。
  12. 购物车：加购后应付累加、分类角标 +1；购物车明细/移除沿用线上（bottom-bar 图标展开 sheet）。
  13. 下一步：购物车有项 → 进入原有结算页；无项 → toast「请先选择项目」。
  14. 范围边界：其余功能（挂单、结算、支付、办卡等）均沿用线上现有逻辑。
  15. 角色权限：店员 / 店长 / 店主，仅列角色，权限沿用线上。

10验收 P0 + 造数场景

10.2 Given → When → Then（P0）

顾客卡片 / 顾客列表

  1. Given 散客开单页，When 点击女头像，Then 女头像彩色、男头像灰阶、文案变「女散客」；再点男头像恢复「男散客」。
  2. Given 散客卡默认态，When 首次进入，Then 男散客选中（男彩女灰），文案「男散客」。
  3. Given 散客开单页，When 点击「选择顾客」，Then 进入顾客列表，顶部有「男散客」「女散客」选项。
  4. Given 顾客列表，When 选「女散客」，Then 返回来源页，散客卡更新为女散客。
  5. Given 顾客列表，When 选会员（如陈女士），Then 顶部切换为会员卡；从 s1 进入时跳 s5。
  6. Given 会员身份，When 点「更换顾客」选男散客，Then 切回散客卡（从 s5 进入则回 s1）。
  7. Given 会员列表，When 查看 VIP 标签，Then 微调后的渐变 ◆VIP 样式正确；文案/逻辑以线上现有 VIP 标签为准。

会员卡权益展开

  1. Given 会员卡，When 查看权益区，Then 全部权益展开显示（计次/储值/折扣），无折叠入口。
  2. Given 会员卡，When 重复进入，Then 权益始终展开、不可折叠收起。
  3. Given 会员卡，When 查看字段，Then 显示规则维持现有（余N次 / 余额xx元 / x.x折）。

添加项目/产品 sheet

  1. Given 项目卡片，When 点圆形加号，Then 打开添加 sheet，标题为项目名 + 红色价格。
  2. Given 添加 sheet，When 步进数量，Then 应收 = 单价 × 数量；实收 = 应收 × 当前折扣。
  3. Given 添加 sheet，When 手动改应收，Then 实收按新应收 × 折扣联动更新。
  4. Given 添加 sheet，When 设折扣（如 5 折），Then 实收 = 应收 × 0.5，折扣文案「5 折」。
  5. Given 添加 sheet，When 手动改实收为任意值后失焦/确定，Then 吸附最近 0.5 折档位，实收改写为该档对应值，折扣文案同步。
  6. Given 添加 sheet（项目），When 查看员工行，Then 标签「服务员工」，未选显示「请选择」。
  7. Given 添加 sheet（产品），When 查看员工行，Then 标签「销售人员」。
  8. Given 添加 sheet，When 点确定，Then 应付总额累加实收金额、分类角标 +1、toast「已加入 · 应付 ¥x.xx」、弹层关闭。
  9. Given 添加 sheet，When 点遮罩关闭，Then 不写入购物车。

折扣标尺

  1. Given 设置折扣 sheet，When 拖动标尺，Then 档位 0.5 折步进，端点标签「免费」「原价」、中点「5折」。
  2. Given 设置折扣 sheet，When 设到 0 档，Then 折扣文案「免费」，实收 = 0。
  3. Given 设置折扣 sheet，When 点确定，Then 返回添加 sheet 并联动实收。

选择员工

  1. Given 选择员工 sheet，When 点员工卡片，Then 卡片翻转显示「点客 / 散客」。
  2. Given 已选「点客」，When 进入下一步，Then 翻转显示「小工 / 中工 / 大工」。
  3. Given 员工完成选择，When 查看，Then 卡片带勾选角标；添加 sheet / 快速消费回填「姓名·点客·大工」。
  4. Given 员工 sheet，When 多选多位员工后完成，Then 全部回填，顿号连接。
  5. Given 员工 sheet 关闭后再次打开，When 查看，Then 已选员工保留勾选状态不重置。
  6. Given 员工 sheet，When 未选员工直接完成，Then 允许关闭，回填区显示「请选择」。

快速消费

  1. Given 快速消费页，When 不输入金额点「去收款」，Then toast「请先输入金额」，不跳转。
  2. Given 快速消费页，When 输入金额后点「去收款」，Then 进入去收款页并显示该金额。
  3. Given 快速消费页，When 点「员工」行，Then 打开选择员工 sheet，选填。
  4. Given 快速消费页，When 点「备注」行，Then 打开备注 sheet，可输入 ≤200 字，计数实时更新。
  5. Given 去收款页，When 修改金额，Then 键盘可改，员工/备注与快速消费页共享同步。
  6. Given 快速消费，When 从 s4 选会员后进入，Then 顶部显示会员卡；选散客后显示散客卡。

金额格式边界

  1. Given 金额键盘，When 输入 .5，Then 以「.」开头被拒绝，不进入。
  2. Given 金额键盘，When 输入 0123，Then 前导 0 剔除，结果为 123。
  3. Given 金额键盘，When 输入 999999.999，Then 小数第 3 位被拒；总值不超过 999999.99。
  4. Given 金额键盘，When 输入 9999999，Then 超上限被拒。
  5. Given 金额键盘，When 输入 58.95，Then 合法显示；再输数字被拒（小数已 2 位）。
  6. Given 添加 sheet 应收/实收，When 输入超过 999999.99 或 2 位以上小数，Then 自动截断/封顶。

下一步 / 底部

  1. Given 购物车为空，When 点「下一步」，Then toast「请先选择项目」。
  2. Given 购物车有项，When 点「下一步」，Then toast「已进入开单结账，请按现有流程完成结算」（线上：进入原有结算页）。
  3. Given s1/s5，When 点底部购物车图标，Then 展开购物车明细 sheet（沿用线上现有实现）。
  4. Given 任意页，When 点「挂单」，Then toast「已挂单」（线上按现有逻辑）。
